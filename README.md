# Mallu AI 🌴

A Kerala-themed modern AI chat interface.

## Project structure

```text
mallu-ai/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

Open `index.html` in a browser.

## Deploy to GitHub Pages

1. Create a GitHub repository.
2. Upload **all four files** to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.

## Deploy to Vercel

Import the GitHub repository into Vercel. No build command is required for this static project.

## Important

This version is a front-end demo. The chat UI works, but actual AI responses require connecting a secure backend/API.
